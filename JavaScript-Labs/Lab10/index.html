Lab 10: JavaScript 3: jQuery

Dùng thư viện jQuery để chọn phần tử, xử lý sự kiện, thêm phần tử, tạo hiệu ứng và gửi GET request.

  • Cài jQuery bằng CDN kèm bản dự phòng
  • Bộ chọn, sự kiện, chèn phần tử DOM, animation
  • GET request và xử lý kết quả bằng jqXHR
Lưu ý: Exercise 10.9 và 10.10 gửi request bằng AJAX nên hãy mở qua GitHub Pages hoặc Live Server (không mở trực tiếp bằng file://). Nếu web service của giáo trình không truy cập được, trang tự dùng dữ liệu dự phòng trong Lab10/data/cities.json.
