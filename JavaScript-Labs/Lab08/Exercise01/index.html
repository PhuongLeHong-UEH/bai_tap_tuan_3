Lab 08 • Exercise 8.1 – Enabling/Disabling JavaScript

Kiểm tra JavaScript đang bật hay tắt

You have JavaScript disabled

Cách bật / tắt JavaScript để kiểm tra

  • Chrome / Edge: nhấn F12 → Ctrl + Shift + P → gõ Disable JavaScript → Enter, sau đó tải lại trang (F5). Làm lại với Enable JavaScript để bật lại.
  • Firefox: mở about:config, tìm javascript.enabled rồi đổi true/false.
  • Trang kiểm tra gốc của giáo trình: examples.funwebdev.com/JavaScriptTest.php (nếu còn truy cập được). Trang này là bản tự làm có cùng chức năng.
